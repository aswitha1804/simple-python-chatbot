# Simple Python Chatbot

This is a beginner-friendly chatbot project built using Python and Tkinter.

The chatbot can interact with users through a simple graphical user interface (GUI). It gives random replies for different inputs and can also answer a few basic math questions.

## Features
- GUI-based chatbot
- Random chatbot replies
- Math response feature
- Enter key support
- Simple and clean interface

## Technologies Used
- Python
- Tkinter
- Random module

- GUI development using Tkinter
- User input handling
